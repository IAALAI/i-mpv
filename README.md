# i-mpv

dev for [external player](https://github.com/LuckyPuppy514/external-player) a Scheme Handler

## 食用方法

将项目扔到预期的目录下,比如/var/impv,随后 sudo 执行 `./install.sh`

左下角打开 `external-player` 的设置,就这个小齿轮

![in setting](https://r.iaalai.cn/i-mpv/in_setting.png)

再点击左下角的新增,把 `event.js` 复制到 `播放事件` 之中即可

![append](https://r.iaalai.cn/i-mpv/append.png)

## 必要依赖

必须提前安装 `mpv` 以及 `external-player`
